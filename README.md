# 腕上RSS

鸿蒙手表的 RSS 与视频内容客户端：在手腕大小的屏幕上读资讯、看哔哩哔哩和抖音。

- 目标设备：智能手表

> 本项目是**非官方**第三方客户端，与哔哩哔哩、抖音、知乎均无关联或授权关系。

## 功能特性

### RSS 资讯

- 预置订阅源：3DM 新闻中心、知乎日报、知乎热榜（走 RSSHub），以及直连官方的 IT之家 RSS
- 添加、删除、排序自定义订阅源；订阅表持久化在关系型数据库
- 阅读页图片可一镜到底全屏查看

### 哔哩哔哩

- 登录与退出登录
- 首页个性化推荐、视频搜索（带搜索历史）
- 视频详情与播放
- 我的收藏夹、关注列表、观看历史

### 抖音

- 精选流、我的收藏、我的喜欢
- 原生 AVPlayer 播放，支持详情与播放链接刷新
- 表冠翻页与音量调节

### 交互与设置

- 卡片堆叠式菜单，哔哩哔哩与抖音共用同一套布局与手势

## 运行环境

| 项 | 值 |
| --- | --- |
| 设备类型 | `wearable`（智能手表），不支持手机与平板 |
| 运行时 | HarmonyOS |
| 目标 SDK | `6.0.0(20)` |
